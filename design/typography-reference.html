Build a grounded action in Copilot Studio

Connect a useful answer to trusted data, a deliberate action, and evidence the reader can inspect.

24 MIN / UPDATED AUG 26, 2026 / AI + COPILOT

A fluent answer can still be incomplete. Grounding gives the response a source, but the reader also needs to understand what happened next and why the result deserves trust.

Begin with the decision

Start by naming the decision the action supports. Then identify the smallest piece of data required to make that decision well. This keeps the implementation focused and makes the resulting evidence easier to read.

Connect the source

Keep configuration names explicit, use a stable sourceId, and provide a visible path back to the source. Read the responsive scale before finalizing the page.
