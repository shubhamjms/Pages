An agent boundary is useful only when builders can locate it and readers can understand its effect.

## Instructions are not permissions

Instructions shape behavior, while permissions determine capability. Asking an agent not to access a record is not a substitute for removing that access.

## Make escalation ordinary

A handoff is not a failure. It is a designed outcome for uncertainty, high-impact changes, and situations where a person has context the system does not.

## Keep review points close

Place confirmation near the action it governs. A generic warning at the beginning of a long process does little to support judgment at the moment it matters.
